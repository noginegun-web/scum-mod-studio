# SCUM Mod Studio 0.1.18

## Исправление обновлений

- Исправлен `RepoUrl` автообновления: программа снова проверяет и скачивает обновления из основного репозитория `noginegun-web/scum-mod-studio`.
- Релизные скрипты теперь по умолчанию публикуют Velopack assets в `https://github.com/noginegun-web/scum-mod-studio`.
- Документация релизного процесса обновлена, чтобы следующие версии не уходили в отдельный release-only репозиторий.

## Включает изменения 0.1.17

- Улучшенная автозамена моделей оружия, шлемов, брони, транспорта, контейнеров и NPC.
- Улучшенный профиль двуручного оружия и сдвиг модели к зоне второй руки без растягивания текстур.
- План разборки armor set на игровые слоты.
- Zombie blueprint и armed NPC spawner preset ассеты в категории "Враги, орды и события".
- Более понятный интерфейс с подсветкой выбранных категорий и скрытыми ручными блоками.
