# SCUM Mod Studio 0.1.17

## Главное

- Добавлена более удобная автозамена моделей для оружия, шлемов, брони, транспорта, контейнеров и NPC.
- Улучшен профиль двуручного оружия: модель сдвигается к зоне второй руки без растягивания UV/текстур, толщина рукояти по умолчанию не меняется.
- Добавлен план разборки armor set на игровые слоты: шлем, торс/жилет, руки, ноги и ботинки.
- В категорию "Враги, орды и события" добавлены zombie blueprint и armed NPC spawner preset ассеты.
- Интерфейс стал понятнее: выбранные категории подсвечиваются, стартовый раздел теперь ведет к оружию/предметам, ручные блоки скрыты до необходимости.

## Raw-модели и toolchain

- Поддерживаются `.fbx`, `.obj`, `.glb`, `.gltf`, `.dae`, `.stl`, `.ply`, `.blend` и архивы `.zip/.rar/.7z`.
- Добавлена проверка toolchain для UnrealPak, UE4.27 и Blender.
- Программа показывает пользователю, чего не хватает для полного raw -> cooked pipeline.

## Безопасность модов

- Для шлемов сохраняется безопасный контракт worn/static mesh и не трогается внутренний component export.
- Для транспорта добавлены предупреждения по query/collision/skeletal контрактам и отдельный план модулей.
- Для NPC/zombie видимые ассеты проходят через safe-фильтр каталога.

## Проверки

- `dotnet build --no-restore`: успешно, 0 warnings, 0 errors.
- `node --check ui/app.js`: успешно.
- UI smoke: категории подсвечиваются, поиск `examine_scavenger_03_v08` находит safe NPC asset, ошибок консоли нет.
